# Rethinka · 首次体验原型

一个可点击的 onboarding 原型：把「模糊的投资直觉」变成「有证据、有结构、有纪律的决策」。

**[▶ 在线体验](https://zhenweiwang1990.github.io/rethinka-onboarding-prototype/)**

左边是手机界面，右边是设计说明——每一屏为什么这么做，都写在旁边。

---

## 这个原型在回答什么问题

新用户第一次打开一个投资研究工具，通常会遇到三种开场：功能导览、风险问卷、空白 Dashboard。三种都很糟——它们都要求用户先付出，才可能拿到价值。

这个原型试的是另一条路：**进来就从用户的下一笔交易开始，5 分钟内让他手里多出一张能复盘的决策卡。**

对应的目标：

- 90 秒内看到第一张结构化决策卡（TTFV < 90s）
- 5–10 分钟走完「想法 → 证据 → 结构 → 纪律」一个闭环
- 离开时至少留下一个命题 + 一条纪律规则
- 全程不需要连券商，不碰真实交易

## 四条路径

原型顶部可以切换四个入口，每条都能完整走完：

| 入口 | 用户状态 | 关键设计 |
| --- | --- | --- |
| **分析一笔交易** | 有想法，想验证 | 四步引导，每步都有降压出口 |
| **复盘我的持仓** | 已买入，心里没底 | 核心一问「当初为什么买」——答不出来本身就是诊断结果 |
| **找一个机会** | 没头绪 | 不推票，先问「你对哪块本来就有感觉」 |
| **按住说话** | 想跳过点选 | 一句话解析出四个字段，直接跳到最关键的那一问 |

## 三个核心设计决定

### 1. 每答必回应

每一个选项都有专属回应，不是「好的，下一题」。选「我觉得会跌」，它会说「做空最怕的是对的太早」；选「真的想不起来了」，它会说「一笔你说不出理由的仓位，其实一直在替你做决定」。

回应不是礼貌，是**证明听懂了**——而且顺便把专业度露出来。

### 2. 逐条浮现，按字数留时间

内容不是一次性铺满。每屏播一个序列：

```
用户选择回显 → 正在输入… → 专属回应 → 停顿 → 下一个问题 → 选项
```

停顿长度按上一句的字数算（约 34ms/字，封顶 1.15 秒）。最后一句说完直接给选项——**没人愿意读完之后再等**。任何时候点一下空白处可以跳过等待。

### 3. 「说不准」是一等公民

每一屏都有一个降压出口，而且**选了之后 AI 行为真的不同**：选「真说不准」，决策卡会切换成正反证据对称呈现、不给推荐方向。降压选项如果不改变下游行为，就只是安慰剂。

## 结尾：研究台

流程不停在「完成页」。最后一屏展示的是**用了三周之后的样子**——因为空 Dashboard 说服不了任何人，但一张「你已经判断对 4 次、错 2 次」的记分卡可以。

包含四块：判断记录（记分卡）、在跟踪的命题、证据变化、集中度暴露。

七日回访的真正驱动力不是提醒推送，是**「我想知道我上次那个判断到底对没对」**。

## 本地运行

纯静态，没有构建步骤：

```bash
python3 -m http.server 4599
# 打开 http://127.0.0.1:4599/
```

## 文件

```
index.html    结构：左手机 + 右说明面板
script.js     对话图谱：26 个节点、文案、每个选项的回应
app.js        渲染与节奏引擎、各屏渲染器、演示数据
styles.css    设计系统（对齐 fin-mobile 主题）
```

改文案只需要动 `script.js`；改视觉只需要动 `styles.css`。
